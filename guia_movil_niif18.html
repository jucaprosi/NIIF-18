Guía Rápida:
Plataforma NIIF 18

Aprende a ejecutar tu cierre contable en 6 pasos utilizando nuestra nueva plataforma de Reclasificación Corporativa.

💡 Tip: Desliza hacia la izquierda para ver cada fase del proceso operativo.
Desliza ➔
📥

Fase 1: Ingesta

Carga los saldos en bruto de tu sistema ERP.

✓ Arrastra y suelta la Balanza de Comprobación (CSV/Excel).
✓ Verifica que el sistema marque "Tolerancia Cero" (cuadre perfecto).
🏷️

Fase 2: Reclasificación

Asigna categorías a las cuentas.

✓ Usa la tabla para clasificar cuentas de Inversión, Financiación e Impuestos.
✓ Recuerda: La categoría "Operativa" es residual (asignada por defecto).
📊

Fase 3: Árbol EEFF

Verifica los subtotales automatizados.

✓ Audita los 3 subtotales obligatorios generados.
✓ Uso de Gráficas: Analiza la gráfica de barras central para comparar visualmente el margen operativo contra la utilidad neta.
✓ Despliega las categorías jerárquicas inferiores para detalles.
📈

Fase 4: Conciliación MPM

Ingresa medidas gerenciales (ej. EBITDA).

✓ Define tu MPM y conéctala a un Subtotal NIIF.
✓ El sistema calculará el impacto y el efecto fiscal para la nota a los estados financieros.
📑

Fase 5: Exportación

Descarga tus papeles de trabajo finales.

✓ Haz clic en "Descargar Excel/CSV".
✓ Entrega este reporte validado directamente a tus auditores.
📚

Fase 6: Soporte Doctrinal

¿Tienes dudas normativas?

✓ Consulta la pestaña del Visor Doctrinal en la App para leer resúmenes directos del IASB sin salir de tu ventana de trabajo.

✅ ¡Estás listo para iniciar tu cierre NIIF 18!
