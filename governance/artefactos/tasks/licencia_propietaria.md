# Licencia propietaria
## **Proyecto:** NIIF 18

**Estado:** Completada — (v3.5)

El repo tenía licencia MIT (`Add MIT License for open source`, commit `96ca67d`) — permitía a cualquier tercero usar, copiar, modificar y **vender** el software libremente, lo cual contradice el plan de una versión de pago. Se comparó contra el modelo de licenciamiento de software de cumplimiento normativo similar (BlackLine, FloQast, Vanta, OneTrust, herramientas de implementación ISO/INEN) — ninguno es open-source; el activo valioso en este tipo de software es el mantenimiento continuo de reglas normativas correctas, no el código en sí. Se reemplazó `LICENSE` por un aviso de copyright propietario explícito ("Todos los derechos reservados"), consistente con el pie de página ya usado en `governance/artefactos/*.md`. Alternativa considerada y descartada por ahora (el propietario puede retomarla): PolyForm Noncommercial/Shield, si en el futuro se quiere mantener el repo público sin permitir uso comercial de terceros.
