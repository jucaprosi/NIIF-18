# Auditoria ifrs converter
## **Proyecto:** NIIF 18

**Estado:** Completada — (v3.4)

A pedido del propietario, se auditó la confiabilidad y licencia de `IFRS-Converter` (GitHub) contra la API de GitHub directamente (no solo el README). Hallazgos: repo de 2 días de antigüedad, 0 estrellas/forks, sin adopción externa; sus reglas de clasificación están marcadas `VERIFIED_SECONDARY` (mismo nivel de incertidumbre normativa que este proyecto, no una fuente más autoritativa); **sin archivo LICENSE** (`license: null` en la API, HTTP 404 en `LICENSE`/`LICENSE.md`) — repositorio público sin licencia conserva todos los derechos de autor por defecto, así que **no se puede copiar/adaptar su código sin permiso explícito**. Se confirma la decisión ya tomada de no reutilizar código, solo arquitectura como referencia. Ver `PRD.md` §9.2.
